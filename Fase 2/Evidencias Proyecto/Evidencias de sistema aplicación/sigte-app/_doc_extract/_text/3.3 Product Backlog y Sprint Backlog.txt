1.2 Patrón de comparación
Para estimar los puntos de historia, el equipo utilizará Planning Poker con una escala de Fibonacci de 1, 2, 3, 5, 8 y 13 puntos. Cada integrante realizará su estimación de forma independiente y luego se compararán las propuestas. Si existen diferencias, se revisará la historia y se acordará un valor común considerando su complejidad, esfuerzo, cantidad de trabajo e incertidumbre. Como referencia, se utilizará una historia previamente estimada para comparar el esfuerzo relativo de las demás.
2. Comprometer historias de usuario
